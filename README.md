# turcss.github.io

Website for the Texas Undergraduate Research Conference for Social Sciences (TURCSS), hosted with GitHub Pages at https://turcss.github.io.

Plain HTML and CSS, no build step. Edit a page on GitHub (pencil icon), commit, and the live site updates within a minute or two.

- `index.html`: home
- `why-attend.html`: Why Attend
- `schedule.html`: key dates and program
- `assets/css/style.css`: shared styles
- `assets/img/`: images

The header, call-to-action, and footer are repeated on each page. Update dates, links, and contact info in all three files.
